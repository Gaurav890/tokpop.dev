# Collector 0.2.3

Publish and verify the package before deploying the website's updated setup command.

## Changes

- Fall back to retained local token counters when account usage is unavailable or unsupported.
- Mark retained history as partial coverage and avoid adding it to overlapping account totals.
- Include archived sessions and preserve a custom data directory in the background updater.
- Open device approval in the default browser when supported, with a manual link and `--no-browser` fallback.
- Include all required modules in both the published package and installed background collector.

## Existing paired devices

Run these commands on the computer that holds the activity. No new pairing is required.

```sh
npm exec --yes --package=ai-native-profile@0.2.3 -- ai-native-profile sync
npm exec --yes --package=ai-native-profile@0.2.3 -- ai-native-profile watch --install
npm exec --yes --package=ai-native-profile@0.2.3 -- ai-native-profile doctor
```

The second command replaces the installed background collector. A one-off sync alone does not upgrade that copy. A partial source-coverage label is expected for retained local history; it does not by itself mean the scheduled job failed.
