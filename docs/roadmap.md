# Public roadmap

## v1

- Cloud dashboard, profiles, cards, schemas, scoring, device collector, five coding adapters, GitHub public delivery, remote MCP, and local export aggregation
- Adapter health telemetry that records failures and versions without request content
- Private alpha using synthetic fixtures and consenting accounts

## Next

- GitHub App installation flow for private-repository delivery aggregates and GitHub-backed canonical snapshots
- Organization connectors for admin-authorized managed-workspace analytics
- Additional provider adapters selected through public capability requests
- Opt-in comparison pages and profile achievements

Provider requests should include a link to an official API, export, telemetry format, or stable local source; the desired aggregate fields; retention behavior; and whether the source can distinguish exact, derived, and estimated values. Unsupported cookies, private endpoints, and internal tokens are out of scope.
